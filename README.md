# Songs & Swords - Starter Content

A companion module for the [Songs & Swords](https://github.com/ryanwhistler93-star/Songs-Swords-System) Foundry VTT system, providing premade Actors and Items (professions, races, NPCs, weapons, etc.) to help new users get started quickly.

## Requirements

Requires the Songs & Swords system to be installed.

## Installation

1. In Foundry VTT, go to **Add-on Modules → Install Module**.
2. Paste the manifest URL: `https://github.com/ryanwhistler93-star/Songs-Swords-Content/releases/latest/download/module.json`
3. Enable the module in your world's Module Management settings.
4. The premade content will appear under **Compendium Packs** in the sidebar.

## Contents

- **Songs & Swords - Starter Actors** — premade Characters/NPCs
- **Songs & Swords - Starter Items** — premade Professions, Races, Weapons, Categories, etc.
